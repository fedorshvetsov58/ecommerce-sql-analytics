# E-Commerce SQL Analytics

Simple Python + SQLite project for analyzing store sales, customer groups, and top products.

## What is inside

- `schema.sql` — creates 4 tables (`customers`, `products`, `orders`, `order_items`) with primary/foreign keys and checks.
- `queries.sql` — 5 SQL queries using `JOIN`, `GROUP BY`, `HAVING`, `CASE WHEN`, `COALESCE`, CTE (`WITH`), and `RANK()`.
- `main.py` — creates the SQLite database, adds test data, and prints all query results as tables in the terminal.
